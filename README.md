Bu proje, bitki yapraklarındaki hastalıkları gerçek zamanlı ve yüksek doğrulukla tespit etmek amacıyla YOLOv8 (Transfer Learning) kullanılarak geliştirilmiştir. 

## 📌 Proje Özeti
* **Model:** YOLOv8n (Nano)
* **Veriseti:** PlantDoc (30 Farklı Bitki/Hastalık Sınıfı)
* **Eğitim Süresi:** 30 Epoch
* **Görüntü Boyutu:** 640x640

## 🚀 Kullanılan Teknolojiler
* Python
* YOLOv8 (Ultralytics)
* OpenCV, PyTorch
* Kaggle (GPU T4 x2)
